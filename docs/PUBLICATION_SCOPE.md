# Public repository scope

Owner explicitly requested this source handoff to `Haydnlee31/BossLab`. The repository was empty and public at inspection. This is a curated source/assets handoff, not a mirror of the entire workstation or a public game deployment.

Tracked: project source, scripts, original brief, current/historical written reports, original `/Game/BossLab` assets and synthesized audio, current V13 runtime geometry, selected original Blender checkpoints/rebuild inputs, selected generated concept targets and actual local study evidence. `docs/PUBLICATION_FILES.json` lists explicitly selected ignored assets; ordinary source/document files are tracked through Git.

Excluded and kept locally: Epic template mannequin assets, engine/Blender installations, generated Binaries/Intermediate/Saved/cache directories, packaged apps, downloaded reference video/frames, large historical captures/archives, local environment/credential files and PPO checkpoint binaries. These files are not silently replaced with placeholders. Restore Epic dependencies with `UNREAL_RESTORE.md`; install tools through your own supported setup. Art scripts expect project-local Blender and contain historical workflow assumptions.

Selected authored Blender files retain their packed materials as local scene content. Earlier scripts may require pruned historical inputs and are not all reproducible. Current V13 rebuilding depends on retained V10 packed input, V13attempt04, V12 shared landmark JSON and generated steel texture. Older V10 recreation from V9 is not complete after prior cleanup; retaining the packed V10 input is intentional.

Historical logs/JSON/reports may identify the original workstation via absolute paths. They are provenance, not portable instructions. Source and documentation received a bounded secret-pattern scan before staging; this is not a formal security certification. No license grant was invented by the assistant. The owner may choose an original-project license separately; Epic/tool/reference rights remain separate.

Many historical Markdown links point to local evidence intentionally not uploaded or previously pruned. Start from HANDOFF.md for the maintained entrypoints. Earlier saved hash audits remain dated evidence; pruning manifests explain later removals.

Only source-safe assets are selected for the initial commit. No Git LFS service, release upload, CI job, Pages deployment or repository visibility change is part of this handoff.
